## Shared engineering

Implemented: pnpm/TypeScript, Next App Router, two Vite PWAs, Express/Socket.IO, PostgreSQL/PostGIS, outbox/expiry worker, six migrations, required core schema, fictional seeds, role/agency/unit scopes, cookie sessions/scrypt/throttling/origin checks, receipt hashing/expiry, canonical chains, transactional idempotency/version/assignment constraints, shared English `en-NG` and Lagos/UTC semantics, fixed role themes, responsive/focus/reduced-motion states, API/security/localisation/scenario/realtime/browser/axe/visual tests, fault/load experiments and GitHub Actions configuration.

OpenAPI inventory and strict Zod requests exist; comprehensive runtime response validation and endpoint-specific response schemas remain partial (receipt responses are validated). The file signer is secured for a local research owner; independent key custody and retained checkpoints are prerequisites for stronger assurance. Optional historical synthetic telemetry is not collected. Scheduled history erasure and client-command TTL cleanup are not implemented; automatic deletion is not claimed. GitHub Actions remote execution must be checked independently.

## Verification boundaries

- Windows 11/Docker Desktop **not executed**; PowerShell setup and troubleshooting are in [WINDOWS_11.md](WINDOWS_11.md).
- Real road import/route smoke tests require approved cloud network access. Missing data stays visibly unavailable, with no fabricated ETA.
- Linux Chromium, axe and deterministic unmasked snapshots (only the header clock is hidden) do not replace manual screen-reader, cross-browser/device, penetration or usability testing. Linux baselines are not Windows baselines.
- Local throughput/fault recovery applies to this host/dataset; it cannot establish production capacity or emergency response improvement.
- No public deployment, real emergency integration, live fleet tracking, outgoing SMS/USSD, production identity/MFA or physical-arrival verification exists. These are outside the research-simulation boundary.

Original specifications are preserved unchanged at repository root. Open items prevent a blanket claim that the entire definition of done has been independently verified.
