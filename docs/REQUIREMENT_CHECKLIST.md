# Requirement coverage

The original version 3.0 specification and build brief remain the scope contract. This table distinguishes implemented behaviour, executable evidence and validation limits. The final executed suite passed 75 domain/database/realtime/scenario checks and 14 production browser/accessibility/visual checks. No screen is a disconnected mock; all workflow data comes from the shared API/database.

## Engineering and reliability

| Requirement             | Implementation / evidence                                                                                                                                                                           |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Specified architecture  | pnpm TypeScript workspace; Next.js, two Vite PWAs, modular Express, Socket.IO, PostgreSQL/PostGIS and separate worker; actual builds pass                                                           |
| Persistent schema       | Versioned SQL contains all 19 required tables plus sessions/settings; optional historical synthetic telemetry is intentionally not collected                                                        |
| Concurrency and retries | Actor-scoped fingerprint/key, client-request uniqueness, aggregate/unit locks, partial indexes; competing dispatcher/unit and retry tests                                                           |
| Atomic events/outbox    | State, original event, durable outbox, idempotency result and coarse security audit commit together; nested scenario transaction context                                                            |
| Worker and reconnect    | SKIP LOCKED batches, bounded retry, notification-dispatch tracking, expiry processing, authoritative REST replay/snapshot reconciliation                                                            |
| Offline privacy         | Public-only static PWA cache, minimal local commands, no API-response cache; offline bootstrap uses an expiring fictional identity label without granting server authority                          |
| Audit semantics         | Canonical SHA-256 with sequence/time/actor/origin/previous hash; append-only trigger, corrections and local checkpoints; Ed25519 signed checkpoints; external anchoring explicitly unavailable      |
| RBAC and abuse          | Session/agency/unit scopes, safe citizen projections, throttled login/API, bounded strict JSON, origin checks, scrypt and HttpOnly/SameSite cookies; CSP/permissions headers on served applications |
| Geography and ETA       | GiST/geography ST_DWithin/metres and longitude-first tests; stale/busy/capability/radius exclusion; no fabricated road ETA                                                                          |
| Localisation            | Shared en-NG catalogue/provider, stable enum labels, Intl UTC/Lagos semantics, static-key inventory, interpolation/plural tests and browser locale fallback                                         |
| UI/accessibility        | Fixed role themes, Radix dialogs, labels/focus/skip links/44px controls/reduced motion, list companions; five-surface axe and masked visual baselines                                               |
| Research experiments    | Five seeds at 100/500/1000 concurrent requests, actual 15s/60s/300s disconnects, emit-only Socket.IO comparison and independent k6; raw measured files retained                                     |
| Documentation/CI        | Root setup/start/test scripts, Windows-friendly commands, architecture/API/threat/localisation/evaluation docs and GitHub Actions                                                                   |
