# UI and interaction system

Canonical identity: NEXUS — Response Intelligence; wordmark NEXUS / RESPONSE INTELLIGENCE. Linked-path icon, no official insignia. Every shell displays the complete research warning and a help link. Public help provides general local guidance without claiming universal emergency-number availability.

Dark command, assurance and admin: #091322 / #102239 / #1B314A, restrained teal #1CC8B1, sky #6BB9F7, amber #F4B95C, coral #F6797B. Citizen: #F5F8FB surfaces and #142235 ink with dark teal actions. Responder: high-contrast dark, large controls and persistent device-outbox/connectivity status. Inter is self-hosted through the dependency bundle; IDs/timings use monospace.

Shared spacing and radii: 4/8/12/16/24/32/48px, 8px controls, 12–16px cards. Keep map queue/data hierarchy and companion lists. Status includes words and icons/dots, never colour alone. Avoid decorative invented KPIs. Counts and measurements come from SQL, with missing values explicitly unmeasured.

Radix accessible dialogs trap focus and require a reason for consequential operator changes. Labels, skip links, visible focus, minimum 44px targets and reduced-motion support are shared. No passive animation under reduced motion. Map canvas has a named accessible region and matching incident/unit lists.

Viewport QA targets 1280×800, 1440×900, 1920×1080; mobile 320×640, 375×812, 390×844; tablet 768×1024. The CAD stacks companion panels on small screens, and provides a drawer width control on desktop. Screenshot artefacts are under artifacts/screenshots; inspect real wrapped text and unmeasured data before accepting baselines.
